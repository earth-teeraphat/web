# วันที่ ประจำวัน ช่วงเวลา สรุปผลการเช็คชื่อ งานที่ปฏิบัติ ภาพหลักฐาน หมายเหตุ จัดการ
รายชื่อเวรทำความสะอาดประจำวัน

นักเรียนชั้นมัธยมศึกษาปีที่ 4/3 โรงเรียนหล่มสักวิทยาคม

แบ่งตามวันจันทร์ - วันศุกร์ ปฏิบัติหน้าที่รักษาความสะอาดห้องเรียน

คำแนะนำการติดตั้งและ Deploy บน Google Apps Script
ขั้นตอนการตั้งค่าใน Google Sheets
  1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  2. ลบโค้ดเดิมใน Code.gs แล้วคัดลอกโค้ดจากไฟล์ Code.gs มาวาง
  3. กดปุ่ม + (เพิ่มไฟล์) เลือก HTML แล้วตั้งชื่อว่า index
  4. นำซอร์สโค้ดในไฟล์นี้ทั้งหมดไปวางในไฟล์ index.html
ขั้นตอนการ Deploy เป็น Web App
  1. กดปุ่ม การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New Deployment)
  2. เลือกประเภทเป็น เว็บแอป (Web App)
  3. ตั้งค่า Execute as: ฉัน (Me)
  4. ตั้งค่า Who has access: ทุกคน (Anyone)
  5. กด Deploy และอนุมัติสิทธิ์ (Grant Access) เพื่อรับ URL ของแอป
